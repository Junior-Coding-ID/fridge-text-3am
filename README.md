## What it does

`main.ts` writes a single line — the text message a smart fridge sends its owner at 3am — to `/output/entry.txt`.

## The entry

> 3:02 AM. Fridge here. Synced with the oven. It got 45 minutes with the lasagna. I've had custody since Tuesday.

111 characters, within the 1–140 character gate.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt` when set).
